## Shared architecture and operations

Next.js/React renders the workspace and uses Supabase Auth. FastAPI validates the bearer session and forwards user-scoped reads to PostgREST so row-level security applies. PostgreSQL functions guard state transitions; service credentials stay with the API and worker. Redis/Celery processes persisted webhook, outbound, and agent jobs; beat reconciles work after broker failures. Docker Compose and the host nginx config in `deploy/nginx/` describe the two-host staging deployment. The [README](../../README.md) has local setup, environment variables, staging, and commands. Tests live under `apps/api/tests`; the Messenger sandbox round trip passed on 18 October 2026.

## What remains before sandbox acceptance

A local Supabase owner, tenant, and Pulse AI Messenger Page connection are configured. The public ngrok callback, inbound webhook, agent job, Meta Send API, and test account receipt passed on 18 October 2026. Instagram and WhatsApp still need channel assets, configuration, and end-to-end tests; Messenger human reply and handoff should also be exercised. The local model endpoint is configured but depends on an external ngrok tunnel and has not passed a real Bangla/Banglish quality evaluation.

The sidebar now routes every observed Presswayy area, but parcels, calls, recordings, ads, broadcasts, chat summaries, billing, tutorials, support, external commerce connectors, and the website widget are availability pages, not implemented workflows. Train Content routes to the existing Agent Studio knowledge editor; Page-post import requires Meta assets and permissions. The Admin Agent currently handles stock, price, product drafts, and FAQ additions; it does not have general administrative powers. The repository has no production deployment. The verified Messenger traffic was through a sandbox Page and local ngrok tunnel.
